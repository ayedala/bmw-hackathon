# Evidence-only operation (historical policy)

Superseded by the user's instruction to restore labelled future drafts and provisional prioritization. See [current decision-support workflow](DRAFT_DECISION_SUPPORT.md). Exact quotation, unknown-data and explicit human-decision safeguards remain active; the prohibition on clearly labelled synthesis/scenarios no longer applies.

The user's current instruction supersedes earlier permission to make reasonable assumptions. The system must not fill missing data or invent future product facts, ratings, forecasts or targets.

- The active portfolio uses stored requirements and source-linked feedback counts. Authored successor templates, future scenarios and illustrative priorities are disabled.
- A generated topic or polarity is an unreviewed classification, not a verified fact. A quotation establishes what a source reported; it does not establish objective truth, prevalence, root cause or future demand.
- Live model output persists only exact source wording as its claim. Model-written outcomes, severity and use-context assertions are discarded. New candidates are evidence topics requiring PM-authored product requirements. Validation methods and targets stay unspecified.
- New YouTube claims use the validated transcript excerpt rather than a model paraphrase. Market/trim/conditions still require review; a video does not determine population demand.
- Priority ratings and weights start blank/zero. No fallback weights or seed factors are applied. Missing input stays unknown. Explicit saved PM preferences are labelled as judgements, never customer facts. Legacy assessments are unconfirmed and do not drive the active portfolio.
- New runs preserve the raw `BEVE` label instead of assuming it means `BEV`. Historical normalized records are not rewritten; source labels and uncertainty remain in the audit history.
- No launch window is inferred. Supplied future sales values remain labelled planning data from their source, never observed future sales.
- The old scripted approval demonstration is disabled. A person must enter their reviewer ID and rationale to make a decision.

Run `.venv/Scripts/python.exe -m streamlit run ui/app.py`, inspect the Evidence tab's exact spans and original source links, edit a requirement from that evidence, then enter explicit PM inputs if prioritization is needed. If there is insufficient evidence, leave the field unknown or defer the decision. Historical scenario calculations are available only as labelled historical policy-dependent calculations; they are not active priorities.

Automatic exact-span checks cannot certify semantic truth. Independent human evidence review is still required. No claim of perfect accuracy is made.
