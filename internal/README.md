# Internal development files

This folder contains agent instructions and working plans. It can be removed as a group when preparing a submission; application code does not load files from here.

- AGENTS.md: canonical instructions for coding agents. Read it explicitly because it is no longer at the repository root.
- agent-guides/: scoped core, test, and UI guidance.
- TASKS.md and IMPLEMENTATION_PLAN.md: progress and remaining work.
- DECISIONS.md: working assumptions and open questions.
- CODEX_KICKOFF.md: the original coding kickoff prompt.

The tool configurations in .codex/ and .entire/ must stay at their expected paths while those integrations are active. Remove them separately if the final submission should exclude agent tooling.
